# 《星环决斗场》

原创 1v1 俯视角 MOBA 浏览器游戏。玩家与电脑英雄在单条星环战线上对线、补刀、升级、购买装备、释放技能、争夺事件并摧毁对方基地核心。游戏使用 TypeScript + Vite + Phaser 3 开发，不需要后端服务。

## 启动方式

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://127.0.0.1:5173/`）。

其他命令：

```bash
npm run build     # TypeScript 检查并生成 dist
npm run preview   # 预览生产构建
npm test          # 运行 Vitest 核心逻辑测试
npm run smoke     # Edge 无头浏览器冒烟测试
npm run flows     # Edge 无头浏览器完整流程验证
```

`npm run smoke` 和 `npm run flows` 使用 Windows 自带 Microsoft Edge 的无头模式与 `puppeteer-core`，不会下载浏览器。

## 模式

- **完整对战**：15 分钟时限，出兵、事件、电脑行为、装备和基地结算全部启用；核心被毁立即胜利或失败，同分时超时。
- **练习模式**：更快出兵，适合测试技能、装备、商店和事件。
- 主菜单提供设置与本地对战记录；设置和最近 20 场记录通过 `localStorage` 保存。

## 操作方式

- 鼠标右键：点击地面移动，点击敌人普攻或追击。
- 鼠标左键：选择单位、确认技能目标、操作商店和按钮。
- `Q / W / E / R`：英雄技能；首次按未学习技能会消耗技能点学习，再次按释放。
- `D / F`：战术技能「跃迁疾行」「复苏信标」。
- `1–6`：使用装备栏中的主动道具。
- `B`：回城，6 秒后回到基地并补满生命法力。
- `空格`：镜头回到自己的英雄。
- `Tab`：按住查看双方等级、K/D、补刀、金币、装备和伤害。
- 鼠标滚轮：缩放镜头。
- 小地图：鼠标左键按下并拖动可移动镜头。
- `P` 或 `Esc`：暂停/继续；暂停菜单支持重新开始和返回主菜单。

技能释放前会显示距离、作用范围或方向。右键或重新选择可取消待释放技能。

## 英雄

所有英雄、名称、技能与视觉均为本项目原创：

- **烬牙·赤刃突进者**：近战爆发型。裂星斩突进单体，熔火护体护盾加速，炽焰横扫范围减速，烬灭千刃突进高伤眩晕。
- **薇洛菈·弧光占星师**：远程消耗型。星辉弹直线能量伤害，极光囚笼区域持续伤害减速，相位跃迁位移，天陨星轨范围轰炸眩晕。
- **索尔瓦·环界守望者**：防御控制型。震地重锤眩晕，星钢壁垒护盾，斥力冲拳击退沉默，星环圣域治疗友军并压制敌军。
- **露米·萤翼游星**：灵活辅助型。萤光飞弹沉默，春星祝福治疗加速，折光跃步双段位移伤害，星籁交响大范围治疗、伤害与减速。

英雄最高 8 级，升级提升属性并获得技能点；R 技能在 6/7/8 级强化。死亡后按等级进入复活倒计时，并在己方基地复活。

## 战斗、兵线和经济

- 普攻分为近战和远程弹道，受攻击距离、墙体与沉默/眩晕限制。
- 伤害分为物理与能量；物理伤害受防御减免，能量伤害受护盾和技能抗性体系影响。
- 控制包含减速、眩晕、击退和沉默；另有护盾、治疗、持续伤害、加速和侦测。
- 每 22 秒双方各出一波兵，包含近战兵、远程兵；每三波以及后期生成重型兵，后期兵线获得属性增强。
- 小兵有近战、远程和重型三类，会沿主路线推进、索敌、攻击并受墙体、技能和防御塔影响。
- 最后一击小兵获得额外金币和经验；附近队友也会获得共享收益。
- 击杀英雄、摧毁防御塔均可获得金币和经验。
- 每方 2 座防御塔 + 1 个基地核心。防御塔优先攻击小兵，敌方英雄在塔下攻击英雄时会转移仇恨；建筑被毁后不会恢复。

## 装备与商店

商店分攻击、防御、技能、移动、恢复、侦查六类。高级装备由低级装备合成，购买后会从差价扣费并替换组件。装备实际改变攻击、生命、防御、法强、移速、攻速、暴击、冷却缩减、射程或提供主动效果。

装备栏最多 6 件，只能在己方基地购买。侦幕晶石可放置 90 秒侦测守卫，用来揭示草丛内敌人。

## 地图与视野

地图包含：

- 一条主要战线和两端基地。
- 上下两侧多组草丛。
- 两处紫色绕后区域。
- 中央中立能量点。
- 多组不可穿越的星环墙体和障碍物。

草丛会隐藏其中的英雄，靠近、进入草丛或通过守卫才能看到；离子风暴会降低视野。电脑英雄也依赖视野，不能直接锁定隐藏在草丛中的玩家。

## 动态事件

比赛会循环出现六类事件，HUD 显示倒计时：

- 强化兵线：立即生成强化援军。
- 中央能量点：进入并持续占领，全队获得治疗、法力和冷却加速。
- 离子风暴：降低视野，草丛外移动速度下降。
- 路线封锁：中央区域出现临时不可通行封锁。
- 基地警报：双方建筑承受额外伤害。
- 极光潮汐：技能冷却和法力恢复加快。

## 电脑英雄

电脑英雄会根据英雄技能进行补刀、推线、技能消耗、追击、撤退、回城和基地购买。它会考虑：

- 自身和敌人的生命值。
- 技能冷却、法力值和距离。
- 兵线位置与最后一击。
- 敌方防御塔范围。
- 草丛和视野，不能隔墙攻击或看到隐身单位。
- 不同英雄的进攻/防守倾向。

## 战况时间线

每局比赛会记录一条轻量的结构化“战况时间线”（不是逐帧录像，也不联网回放），随战绩一起存入 localStorage，作为 `MatchRecord` 的可选 `timeline` 字段，旧记录没有该字段也能正常读取。

- 事件类型：英雄击杀/死亡/复活、炮塔与核心摧毁、动态事件开始/结束、兵线生成、购买装备、主动道具使用、技能释放、回城完成和比赛结束。
- 每条事件包含相对比赛时间、类别（战斗/目标/经济/系统）、队伍、主体名称和简短文本；同一动作不会重复写入。
- 时间线最多保留 300 条，超出时丢弃最旧事件，但比赛结束、核心摧毁等终局事件始终保留，排序稳定。
- 结算页直接展示本场时间线；对战记录页点击任意一场记录可查看详情与对应时间线。
- 面板支持 全部/战斗/目标/经济/系统 四类筛选，并可导出本场时间线 JSON 或 CSV（UTF-8 带 BOM，逗号、换行、引号和中文均安全转义）；导出顺序与当前筛选结果一致，没有事件时只提示、不下载空文件。

## 测试覆盖

Vitest 测试覆盖：

- 英雄移动、近战/远程攻击距离和墙体碰撞。
- 技能冷却、法力消耗、伤害、护盾、减速、眩晕、沉默、击退。
- 英雄升级、技能学习、死亡、复活倒计时和复活点。
- 小兵定时生成、三类兵种、路线推进、攻击和死亡。
- 防御塔目标选择和基地核心胜/负/超时结算。
- 金币、补刀、基地购买、合成价格和装备属性。
- 草丛隐藏、靠近视野、守卫揭示和动态事件。
- 电脑英雄推进和战斗行为。
- 时间线事件类型映射、时间/稳定排序、300 条上限与终局事件保留。
- 击杀/死亡/复活、建筑摧毁、动态事件、购买与道具、技能与回城事件记录。
- 旧记录兼容、四类筛选、未知字段安全处理、JSON/CSV 转义和空状态。
- 页面级：比赛结束到结果页显示时间线并可筛选。

无头浏览器流程实际验证：

- 主菜单 → 英雄选择 → Phaser 对局。
- 鼠标右键移动、技能释放、补刀和基地购买装备。
- 击杀电脑英雄。
- 摧毁敌方基地核心并显示胜利结算。
- 玩家基地核心被毁并显示失败结算。

最近一次验证：`45/45` Vitest 测试通过，`npm run build` 成功，`npm run smoke` 与 `npm run flows` 均通过。

## 美术与资源说明

本项目不使用任何商业 MOBA 的角色、名称、地图、图标或素材。地图、角色图形、技能标识、图标构图和界面均由代码/几何图形/CSS 与原创文本实时绘制生成。
